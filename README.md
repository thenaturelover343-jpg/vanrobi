# VanRobi

Website voor VanRobi — professionele ijsbankkoelers voor horeca in België en Nederland.

De vorige Next.js / GitHub Pages-versie staat op de branch `legacy-nextjs`.

## Lokaal draaien

```bash
npm install
npm run dev
```

Open http://localhost:8080

## GitHub Pages

Deze versie is een Vite/TanStack-app, geen statische Next-export. De oude site op https://thenaturelover343-jpg.github.io/vanrobi/ blijft tot je opnieuw deployt (bijvoorbeeld Vercel).
