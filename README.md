# VanRobi

Website voor VanRobi — professionele ijsbankkoelers voor horeca in België en Nederland.

Live: https://thenaturelover343-jpg.github.io/vanrobi/

De vorige Next.js-versie staat op branch `legacy-nextjs`.

## Lokaal

```bash
npm install
npm run dev
```

Open http://localhost:8080

GitHub Pages bouwt via `.github/workflows/pages.yml` (`npm run build:pages`).
